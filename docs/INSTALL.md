# Установка Lumigram на iPhone с Windows (бесплатно)

## 1. Скачать .ipa из GitHub

1. Откройте свой репозиторий → вкладка **Actions**.
2. Нажмите на последнюю сборку с **зелёной галочкой**.
3. Внизу страницы, в блоке **Artifacts**, нажмите **Lumigram-ipa** — скачается zip.
4. Распакуйте zip (правый клик → «Извлечь всё»). Внутри файл `Lumigram.ipa`.

## 2. Установить программы на компьютер

Sideloadly работает только с «классическими» iTunes и iCloud с сайта Apple, **не из Microsoft Store**.

1. Если iTunes или iCloud стоят из Microsoft Store — удалите их (Пуск → Параметры → Приложения).
2. Скачайте и установите **iTunes для Windows (64-bit)** с сайта Apple: https://www.apple.com/itunes/download/win64 
3. Скачайте и установите **iCloud для Windows** (версия с сайта Apple, ссылка есть на странице загрузки Sideloadly).
4. Скачайте **Sideloadly** с официального сайта https://sideloadly.io и установите. Других сайтов не используйте.

## 3. Подключить iPhone

1. Подключите iPhone кабелем к компьютеру.
2. На iPhone появится «Доверять этому компьютеру?» → **Доверять** → введите код-пароль телефона.
3. Откройте iTunes и убедитесь, что значок телефона появился вверху. После этого iTunes можно закрыть.

## 4. Подписать и установить

1. Откройте Sideloadly.
2. В поле **iDevice** выберите свой iPhone.
3. В поле **Apple account** введите свой Apple ID (почту). Можно завести отдельный бесплатный Apple ID специально для этого — так даже спокойнее.
4. Перетащите `Lumigram.ipa` на большую иконку IPA слева.
5. Нажмите **Start**. Введите пароль Apple ID в окне Sideloadly (он уходит только в Apple). Если включена двухфакторная защита — введите код, который придёт на ваши устройства.
6. Дождитесь надписи **Done**.

Расширенные настройки Sideloadly (Advanced options) менять не нужно.

## 5. Включить режим разработчика (iOS 16 и новее)

1. На iPhone: **Настройки → Конфиденциальность и безопасность → Режим разработчика** (пункт появляется после первой установки через Sideloadly).
2. Включите → **Перезагрузить**.
3. После перезагрузки подтвердите **Включить** и введите код-пароль.

## 6. Доверять профилю

1. **Настройки → Основные → VPN и управление устройством**.
2. В разделе «Приложение разработчика» нажмите на свой Apple ID → **Доверять** → **Доверять**.
3. Откройте Lumigram на главном экране и войдите в свой аккаунт Telegram.

## 7. Каждые 7 дней — переподписать

Бесплатная подпись Apple действует 7 дней. Потом приложение перестанет открываться, но **переписки и вход не пропадут**, если просто переподписать поверх:

1. Подключите iPhone, откройте Sideloadly.
2. Тот же Apple ID, тот же `Lumigram.ipa` (или новый из Actions) → **Start**.

Удалять приложение перед этим **не нужно** (иначе придётся входить заново).

Удобнее: в Sideloadly в выпадающем меню выберите **Auto-refresh** — тогда он будет переподписывать сам по Wi‑Fi, когда компьютер и телефон в одной сети и Sideloadly запущен.

## Ограничения бесплатного Apple ID

- Не больше 3 своих приложений на телефоне одновременно.
- **Нет push-уведомлений**: сообщения приходят, когда приложение открыто или недавно было открыто. Для уведомлений можно оставить официальный Telegram и включить в нём уведомления, а Lumigram использовать как основной клиент.
- Нет виджетов, «Поделиться в Lumigram» и Siri — для них нужны отдельные расширения, которые бесплатный Apple ID не подписывает.

## Если что-то пошло не так

- **«Could not find developer disk image» / телефон не виден** — обновите iTunes, переподключите кабель, разблокируйте телефон.
- **«Maximum number of apps»** — удалите одно из других приложений, установленных через Sideloadly.
- **«Your maximum App ID limit has been reached»** — подождите 7 дней или используйте другой Apple ID.
- **Приложение сразу закрывается** — проверьте шаги 5 и 6, либо пришлите мне скриншот.
