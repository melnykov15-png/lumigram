# Что нужно сделать вам (один раз, ~20 минут)

Всё бесплатно. Нужен только браузер на Windows и телефон с Telegram.

## Шаг 1. Аккаунт GitHub

1. Откройте https://github.com/signup
2. Введите почту, придумайте пароль и имя пользователя (латиницей, например `ivan-petrov`).
3. Подтвердите почту кодом из письма. Тариф — **Free**.

## Шаг 2. Создать пустой репозиторий

Форкать огромный репозиторий Swiftgram **не нужно**: наш репозиторий — маленький «рецепт», который сам скачивает Swiftgram во время сборки и накладывает на него мод. Так проще обновляться и не нужно ничего тяжёлого качать к себе.

1. Откройте https://github.com/new
2. **Repository name**: `lumigram`
3. Выберите **Public** (обязательно: только публичным репозиториям сборка на Mac бесплатна).
4. Галочки «Add a README», «.gitignore», «license» **не ставьте** — репозиторий должен быть пустым.
5. Нажмите **Create repository**.
6. Скопируйте адрес из строки браузера (вида `https://github.com/ВАШЕ_ИМЯ/lumigram`) и пришлите его мне в чат.

## Шаг 3. Получить api_id и api_hash

Это «ключи» вашего клиента Telegram. Они ваши личные — никому их не показывайте (мне тоже присылать не нужно).

1. Откройте https://my.telegram.org и введите свой номер телефона в международном формате (`+7...`).
2. Код придёт **в сам Telegram** (не СМС). Введите его.
3. Нажмите **API development tools**.
4. Заполните форму:
   - **App title**: `Lumigram`
   - **Short name**: `lumigram` (5–32 латинских буквы)
   - **Platform**: `iOS`
   - Остальное можно оставить пустым.
5. Нажмите **Create application**. Появятся **App api_id** (число) и **App api_hash** (длинная строка из букв и цифр). Не закрывайте страницу.

> Если форма выдаёт «ERROR» — это частая проблема сайта. Попробуйте другой браузер, отключите VPN/блокировщик рекламы или повторите через несколько часов.

## Шаг 4. Положить ключи в GitHub Secrets

Секреты хранятся в GitHub зашифрованно, их не видно в коде и в логах.

1. Откройте ваш репозиторий → вкладка **Settings** (шестерёнка вверху).
2. Слева: **Secrets and variables** → **Actions**.
3. Нажмите **New repository secret**:
   - **Name**: `TELEGRAM_API_ID`
   - **Secret**: число api_id
   - **Add secret**
4. Ещё раз **New repository secret**:
   - **Name**: `TELEGRAM_API_HASH`
   - **Secret**: строка api_hash
   - **Add secret**

Имена нужно ввести точно так, заглавными буквами.

## Шаг 5. Разрешить мне загрузить код

Когда пришлёте адрес репозитория, я отправлю туда код. В этот момент на экране **появится окно входа в GitHub** — войдите своим аккаунтом и нажмите **Authorize**. Это нужно один раз.

## Что дальше

Сборка запустится сама. Первая идёт долго (2–5 часов), последующие быстрее за счёт кэша. Если первая упрётся в лимит времени — это нормально, вторая продолжит с того же места. Логи я читаю и чиню сам.
