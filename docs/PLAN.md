# План проекта Lumigram

## Что выяснилось при изучении Swiftgram

| Что | Где | Решение |
|---|---|---|
| Система сборки | Bazel 9.2 через `build-system/Make/Make.py`, только цель `//Telegram:Swiftgram` | Используем как есть |
| Версия Xcode | `versions.json`: Xcode 27.1 | Раннер GitHub `xcode-27` (бесплатный для публичных репо) |
| api_id / api_hash / bundle id / team id | JSON‑конфиг (`build-system/template_minimal_development_configuration.json`) → `variables.bzl` → `BuildConfig` | Генерируем конфиг в CI из GitHub Secrets |
| Название приложения | `Telegram/BUILD`, `CFBundleDisplayName` = Swiftgram | Меняем на Lumigram |
| Иконка | `Telegram/Telegram-iOS/Swiftgram.icon` (формат Icon Composer) | Своя иконка: фиолетово‑бирюзовый градиент, облачко со звездой |
| Расширения (Share, Widget, Notification, Siri, Broadcast) | `Telegram/BUILD`, флаг `disableExtensions` | Отключены: каждое требует отдельный App ID |
| Entitlements | `Telegram/BUILD`, `TelegramEntitlements` | Оставлен только App Group; push, CarPlay, iCloud, Siri, Sign in with Apple, Apple Pay убраны |
| Подпись | Нужен профиль даже для «неподписанной» сборки | Генерируем одноразовый поддельный сертификат и профиль (как `fake-codesigning` в Swiftgram); Sideloadly переподписывает |
| Общий контейнер App Group | `AppDelegate.swift`: без него «Error 2» при запуске | Запасной путь внутри песочницы приложения |

## Риски, о которых стоит знать

- **Время сборки.** Telegram — очень большой проект; бесплатный Mac‑раннер слабый (3 ядра). Первая сборка 2–5 часов, лимит GitHub — 6 часов на запуск. Кэш сохраняется даже при неудаче, поэтому следующий запуск продолжает.
- **Каждая правка проверяется только полной сборкой** (Mac у нас нет), поэтому функции добавляются по одной, а не все сразу.
- **Без push‑уведомлений.** Бесплатный Apple ID их не поддерживает.
